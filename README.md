# Portfolio Website — Lab Assessment


A five-page responsive personal portfolio built with HTML5, CSS3 and plain
JavaScript. No frameworks, no libraries and no build tools are used.



## Folder Structure


portfolio-website/
│
├── index.html              Home page (entry point, must stay in the root)
│
├── css/                    Folder that contains CSS
│   └── style.css           Single external stylesheet for every page
│
├── js/                     Folder that contains the script
│   └── script.js           Single external script for every page
│
├── images/                 Folder that contains images
│   ├── profile.png
│   ├── about.jpg
│   ├── favicon.png
│   └── project-1.png … project-6.png
│
├── pages/                  Folder that contains the other pages
│   ├── about.html
│   ├── skills.html
│   ├── projects.html
│   └── contact.html
│
└── README.md
